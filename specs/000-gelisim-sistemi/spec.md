# Vixrex ortak gelişim sistemi

## Kullanıcı sonucu

Furkan hangi yapay zekâyla çalışırsa çalışsın her yeni özellik ve değişiklik
aynı araştırma, planlama, uygulama, eksik kapatma ve inceleme zincirinden geçer.

## Kapsam

- Ajana özel zorunluluklar kaldırılır.
- Resmî GitHub Spec Kit aşamaları Vixrex için tek sıraya bağlanır.
- Her işin kanıtları tek klasörde tutulur.
- GitHub ortak kapısı eksik zinciri teslimattan durdurur.
- Otomatik canlı yayın kapalı kalır.

## Kabul koşulları

- Deponun ortak kuralları hiçbir ajan adına bağlı değildir.
- Zorunlu sıra DEVELOPMENT.md içinde açıkça yazılıdır.
- GitHub kontrolü eksik iş kaydında kırmızı, tam kayıtta yeşil sonuç verir.
- Teslimat sistemi gelişim zinciri kontrolü geçmeden birleştirme yapmaz.
- Canlı yayın ayrıca onaylanmadıkça başlamaz.
